# Full-Stack Blog App (Next.js + MongoDB)

A complete full-stack blog application built with **Next.js 13 (App Router)** and **MongoDB**.  
This project is inspired by the Lama Dev tutorial and demonstrates how to create a modern blog platform with authentication, CRUD operations, and deployment readiness.

---

## 🚀 Features
- **Next.js 13 App Router** for modern routing and layouts
- **MongoDB** integration for persistent data storage
- **Authentication** with NextAuth.js
- **Responsive UI** built with React components
- **Create, Read, Update, Delete (CRUD)** functionality for blog posts
- **Rich text editor** integration (React Quill)
- **Error handling & API responses** with Axios
- **Deployment ready** for platforms like Vercel

---
